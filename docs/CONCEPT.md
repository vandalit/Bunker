# WARZONE - Concepto

## Brief de producto · Versión 0.1

**Tipo de producto:** Aplicación web de gestión doméstica de alimentos y planificación de reservas.
**Enfoque inicial:** Inventario, abastecimiento, caducidad, cobertura estimada y control de costos.
**Contexto de lanzamiento:** Chile, con posibilidad de adaptación a otros países de Latinoamérica.

---

## 1. Concepto

WARZONE es una aplicación web que permite a las personas construir y administrar una reserva doméstica de alimentos de forma progresiva, dinámica y consciente de sus recursos económicos.
